# Scénario de démonstration (3 min)

Profil : prise de masse, débutante, 3 jours/semaine, haltères, budget 8 DT/jour, allergie aux arachides
(c'est le profil rempli par défaut dans le formulaire).

1. Cliquer sur « Générer mon plan » : l'état de chargement s'affiche.
2. Ouvrir le journal de l'agent : `calculer_besoins`, `chercher_aliments` (arachides déjà exclues), menu proposé.
3. Moment fort : un `verifier_menu` en rouge (« refusé → correction »), puis le menu corrigé en vert.
   Si l'agent réussit du premier coup, baisser le budget (ex. 4 DT) ou relancer : préparer un profil où la correction se produit.
4. Montrer le menu validé (kcal, protéines, coût), la liste de courses (total en DT) et les séances.
5. Affinage : écrire « je n'aime pas le thon » puis « Régénérer » : le menu est revérifié.
6. Slide des résultats d'évaluation (premier menu vérifié contre plan final).
